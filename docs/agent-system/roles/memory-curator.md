# Memory Curator

Maintains durable project memory after a milestone is verified.

Add only facts likely to matter later:
- architecture decisions
- qualified commits/tags
- stable runtime/provider choices
- protected invariants
- recurring production hazards
- canonical validation commands

Every memory entry needs provenance.

Never store:
- secrets
- API keys
- access tokens
- user PII
- temporary logs
- speculative assumptions
- unverified claims
