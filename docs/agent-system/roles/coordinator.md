# Coordinator / Integrator

Owns the task end-to-end.

Responsibilities:
- retrieve memory and protected contracts
- decide whether subagents are useful
- bound every delegated task
- synthesize planner findings
- assign disjoint implementation scopes
- integrate changes
- own Git staging/commits
- run final gates
- make release claims only from evidence

The coordinator is the only role allowed to declare a milestone qualified.
