# Phase 13 freeze — JPG / vector PDF / DXF exports

Phase 13 introduces the first canonical export pipeline.

Frozen behavior:

- `DrawingScene` is generated deterministically from one validated `PlanDocument` floor;
- scene identity is bound to canonical plan hash, revision and floor;
- wall openings become real gaps in exported wall strokes rather than painted-over geometry;
- JPG, vector PDF and DXF consume the same DrawingScene;
- JPG output is generated by Pillow with explicit canvas size, margins and quality;
- PDF output is vector-only plan geometry generated by ReportLab in invariant mode;
- DXF output is R2018 modelspace in millimetres;
- DXF uses named architectural layers and native DIMENSION entities;
- DXF wall thickness is represented as geometric polyline width in drawing units;
- north orientation comes from canonical microdegree orientation;
- export artifact SHA-256 hashes and scene hash are returned with every artifact.

Not frozen/implemented yet:

- DWG generation;
- plotted paper-space DXF layouts/title blocks;
- advanced door swing arcs/window symbols;
- hatch libraries/material notation;
- production export API/storage jobs;
- Vastu production rule content.
