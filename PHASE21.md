# Phase 21 — Production SaaS shell and product workspace

Phase 21 is a UI/UX reframe only. It does not weaken or replace any of the production gates established through Phase 20B.

## Scope

- Add a persistent left-hand SaaS navigation shell.
- Highlight the active page from the current route.
- Reframe the authenticated dashboard into a production SaaS workspace.
- Add a dedicated Projects route with live project search, status, and create flow.
- Keep the existing project-bound canonical editor intact inside the new shell.
- Add product surfaces for Generation, Reviews, Exports, and Settings using only capabilities already present in the repository.
- Expose the frozen Vastu v1 production bundle without inventing a project compliance percentage.

## Non-goals

- No new geometry authority.
- No browser-authored PlanDocument data.
- No fabricated Vastu score.
- No new solver behavior.
- No database schema change.
- No change to the Phase 20B production Vastu bundle or its hashes.

## Visual direction

Professional light-theme SaaS interface with a left sidebar, clear active navigation state, compact top bar, green/teal architectural accents, rounded cards, subdued borders, and responsive behavior.
